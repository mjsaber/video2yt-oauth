隱私權政策

生效日：2026-10-14

video2yt 是頻道擁有者自用的桌面程式。它透過 Google OAuth 向 YouTube Data API 與 YouTube Analytics API 請求存取權，範圍限於「上傳與管理影片」、「讀取頻道資料」與「讀取 Analytics 報表」。

  • 存取權杖只儲存在頻道擁有者本機，不會傳送到任何第三方伺服器。
  • 程式只處理頻道擁有者自己的 YouTube 頻道資料，不收集、不儲存、不分享任何其他使用者的個人資料。
  • Google 使用者資料的使用遵守 Google API Services User Data Policy，包括有限使用（Limited Use）要求。
  • 可隨時在 Google 帳戶權限頁 撤銷授權。
